# Contributing to AgentMesh

We welcome contributions from developers, researchers, and AI engineers!

## Development Setup

```bash
# Clone the repository
git clone https://github.com/Hamidooh/agent-mesh.git
cd agent-mesh

# Install dependencies
npm install

# Run test suite
npm test

# Build project
npm run build
```

## Pull Request Guidelines

1. Ensure all changes pass `npm run typecheck` with zero TypeScript errors.
2. Maintain 100% passing tests via `npm test`.
3. Add unit or integration tests for any new topologies, tools, or memory algorithms.
4. Follow conventional commit messages (e.g., `feat:`, `fix:`, `docs:`, `test:`).
